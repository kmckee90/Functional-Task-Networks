EDIT presentation/proposal.md

This is now the source of the live proposal at http://localhost:8080/.
Save the file and refresh the browser. No build or server restart is needed for
text/media edits. draft_v3.txt is preserved but no longer drives the site.

Headings use normal Markdown:
# Page title
## Major section
### Subsection
#### Smaller subsection

Use **bold**, *italics*, numbered/bulleted lists, and [link text](URL).

MEDIA
Move the whole <figure> ... </figure> block to move an image/video together
with its caption. Edit the text between <figcaption> and </figcaption>.
Change src="..." to replace a file. Image figures also have an href="..."
for opening the full image; update that too when replacing an image.

<div class="result-grid"> ... </div> puts figures side by side. Keep the
whole group together, or move figures outside it to make them full-width.
Inside these HTML blocks, use plain text or HTML (e.g. <strong>bold</strong>),
not Markdown syntax. Leave a blank line before and after a complete block.

A simple new image can also use ordinary Markdown:
![Description](/assets/proposal/my-image.png)

A new captioned video:
<figure class="proposal-film">
  <video controls playsinline preload="metadata" src="/assets/proposal/my-video.mp4"></video>
  <figcaption>Your caption.</figcaption>
</figure>

Put new files in presentation/proposal assets/ and use /assets/proposal/...
URLs. Encode spaces in URLs as %20. Existing generated videos and charts use
/assets/preview/...; these are served from the local hosting media cache.
The URLs are relative to this website, so they work over localhost or Tailscale.
A generic editor preview may not resolve them; the hosted page is the preview.
Videos use HTML because Markdown has no standard embedded-video syntax.
